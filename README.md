# Videoplayer

## How to

1. You get raw video file url: `https://funny-video-file-somewhere`

1. You prefix it with `https://aleksandr.vin/videoplayer/#` and open!

## Where to store your video files

### Backblaze

See https://www.backblaze.com/blog/roll-camera-streaming-media-from-backblaze-b2/
